# Rooktide: Glass Current

An original open-world crime game for the make.fun gta6-01 bounty (Make GTA 6).
Playable offline in a desktop browser from static files. Everything - city,
characters, story, music - is original and generated from code. No Rockstar
assets, names, or music are used.

You are Neri Voss, a courier in the coastal city of Rooktide. Steal the Glass
Current ledger, outrun the Rooktide Civic Patrol, and broadcast the truth
before the next seawall closure.

## Play

Open game/index.html in desktop Chrome. Drive with WASD, get in and out of
cars with E, follow the mission card.

## Build

main.ts (Node 22) copies game and screenshots to the output directory and
writes dossier.json via vendor/makefun-game.ts.
